About Us

Learn about CalcHub — a free online tool platform focused on privacy, speed and useful everyday utilities.

Last updated: November 2026

What is CalcHub?

CalcHub is a free online tool platform with the simple goal of helping you get everyday tasks done quickly and privately. We publish a curated set of utilities for writing, images, calculations, generation, time management and counting.

All tools run as a static website. Pages are lightweight, load fast, and work on phones, tablets and desktops.

What you will find

Six categories of tools:

  • Text Tools — word counts, character counts, case conversion, duplicate removal and placeholder text.
  • Image & File Tools — compress, resize, convert, crop and generate favicons.
  • Calculators — percentage, age, date difference, unit, BMI and discount calculators.
  • Generators & Converters — passwords, QR codes, UUIDs, random data and JSON tools.
  • Time & Productivity — countdown, stopwatch, Pomodoro and time zone tools.
  • Counters & Trackers — simple tally counters.

How we choose tools

We only publish tools that are genuinely useful, work without an account, and can run reliably in a standard browser. We describe features honestly: where a result is an estimate (such as reading time or BMI), the page says so. We do not invent usage statistics, reviews or performance claims.

Privacy by design

Processing happens in your browser. Your text, numbers and files are not uploaded to us, so we have nothing to sell or lose. See the Privacy Policy for details.
