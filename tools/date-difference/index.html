Date Difference Calculator

Find out how many days are between two dates, including an option to count the end date. Results are based on real calendar days, so daylight saving or time zones do not skew the answer.

How to Use

  1. Pick the start date.
  2. Pick the end date.
  3. Choose whether to include the end date in the count.
  4. Read the difference in days, weeks, months and years.

Practical Examples

  • How many days until a project deadline?
  • Trip duration between departure and return dates.
  • Contract length between a start and end date.

Key Features

  • Days, weeks, months and years between dates
  • Option to include or exclude the end date
  • Calendar-day based, immune to DST errors
  • Works across date order (can be negative)
Privacy: All date math happens locally in your browser. Nothing is stored or sent.

Frequently Asked Questions

Does 'include end date' change the result?

Yes. Excluding the end date counts the number of full days between the two dates. Including it adds one day (useful for booking nights or subscription lengths).

Is daylight saving handled?

Yes. We work with calendar dates rather than fixed milliseconds, so DST changes do not affect the day count.

What if I reverse the dates?

The result is shown as a negative number so you can spot the order. Swap the dates for a positive count.
