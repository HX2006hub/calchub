Online Counter

A fast, tactile counter for anything you need to tally. Use the buttons, arrow keys or +/- shortcuts to count up and down, and reset with a click.

0

Tip: with the buttons focused, press +, − or R to count.

How to Use

  1. Click the + button (or press the '+' key) to count up.
  2. Click the − button (or press the '-' key) to count down.
  3. Press Reset to return to zero.
  4. Optionally set a custom step size.

Practical Examples

  • Tally attendees entering a room.
  • Count repetitions during a workout.
  • Track items packed or produced.

Key Features

  • Count up and down
  • Keyboard support (+ / − / R)
  • Custom step size
  • Touch-friendly buttons
  • Optional localStorage persistence (clearly labelled)
Privacy: The counter runs locally. If you enable persistence, the value is stored only in your browser's localStorage and is never sent to a server.

Frequently Asked Questions

Does the counter save when I refresh?

Only if you enable 'Keep count after refresh'. It then saves to your browser's localStorage on this device. Otherwise, the value resets to zero.

Can I count faster with the keyboard?

Yes. Press the + and − keys to count, and R to reset, when the counter is focused.

Can I set a step bigger than 1?

Yes. Change the step size in the settings to jump by any number.
