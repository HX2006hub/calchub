Frequently Asked Questions

What is lorem ipsum?

Lorem ipsum is a pseudo-Latin text used since the 1500s as placeholder content in typesetting and web design. It lets designers judge layout without being distracted by readable copy.

Can I use lorem ipsum in real projects?

Yes. It is intentionally meaningless, so it is safe for mockups. Replace it with real copy before publishing.

Is there a maximum amount?

No. You can generate large amounts of text locally, though we recommend generating only what your layout needs.
