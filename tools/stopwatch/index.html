Online Stopwatch

For timing how long something takes, a start button and an elapsed display are usually enough. This stopwatch measures from the moment you press Start until you stop it.

Online StopwatchRuns in your browser
00:00:00.00

Uses high-resolution timestamps, so it stays correct when you switch tabs.

How to Use

  1. Press Start to begin. The display shows hours, minutes, seconds and hundredths.
  2. Press Stop to freeze the elapsed time at its current value.
  3. Press Start again to continue from where you stopped, or Reset to return to zero.
  4. Read the final figure directly from the display.

Practical Examples

  • Timing how long a task takes: press Start when you begin and Stop when you finish.
  • Measuring a short process of a few seconds, where the hundredths column shows the finer detail.
  • Timing separate attempts by pressing Reset between runs.

Understanding the Result

Like the countdown timer, this stopwatch works from clock timestamps: it subtracts the start time from the current time on each frame. The last two digits are hundredths of a second, derived from the milliseconds value — not a separate high-resolution measurement.

Stop freezes the elapsed value. Starting again shifts the start time backwards by that amount, so the display continues rather than restarting. Reset clears it to zero.

Limitations and Useful Notes

  • There is no lap or split-time feature and no history of intermediate times. To record several intervals, note each value as you go.
  • The hundredths column is a rounded display of elapsed time, not a reading of individual milliseconds, and the display is limited by how often the browser paints a frame.
  • Accuracy depends on your device clock and browser scheduling. It is suitable for everyday timing, not scientific or competitive measurement.
  • There is no sound, alarm or target-time alert.
  • Closing or reloading the tab loses the elapsed time; nothing is saved.
Privacy: Timing happens in your browser. No data is uploaded or stored.

Common Questions

Can I record lap times?

No. This stopwatch has a single elapsed display with Start, Stop and Reset, and it does not store intermediate splits. If you need laps, note the displayed value at each point and reset or continue as needed.

How precise is the display?

It shows hundredths of a second, which are derived from the elapsed milliseconds. Browser frame timing and device clock scheduling limit the real resolution, so treat it as a convenient everyday measure rather than a precision instrument.

Does it keep running in another tab?

The elapsed value is based on a timestamp, so it stays correct when you return to the tab even if the browser throttled its animation frames while it was hidden. The display may jump forward rather than tick smoothly.
