Online Stopwatch

Time anything with a simple, precise stopwatch. Start, pause, record laps and reset — all locally, with high-resolution timing that stays accurate in the background.

Online StopwatchRuns in your browser
00:00:00.00

Uses high-resolution timestamps, so it stays correct when you switch tabs.

How to Use

  1. Click Start to begin timing.
  2. Record laps with the Lap button as needed.
  3. Pause to stop the clock; Start again to continue.
  4. Reset to clear the time and laps.

Practical Examples

  • Timer for a 5 km run split checkpoints.
  • Measure a task to improve your workflow.
  • Run a science experiment with lap recording.

Key Features

  • High-resolution elapsed time
  • Start, pause, continue and reset
  • Lap recording
  • Accurate when the tab is in the background
Privacy: Everything happens locally in your browser. No timing data is stored or transmitted.

Frequently Asked Questions

How precise is the stopwatch?

We use the Performance API's high-resolution time for display, with millisecond precision. Browser scheduling can cause minor delays, but for everyday timing it is accurate.

Does it keep running in another tab?

Yes. The elapsed time is computed from timestamps, so switching tabs does not reset it. Suspended tabs may briefly not update, but the computed time stays correct.

Can I delete a lap?

You can clear all laps with Reset. Individual lap removal is not implemented to keep the interaction simple.
