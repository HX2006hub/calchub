Random Name Picker

Paste a list of names — one per line — and pick one at random. Great for giveaways, classroom selection, team picking and friendly draws.

Random Name PickerRuns in your browser

    How to Use

    1. Paste or type names, one per line.
    2. Add more names with the quick-add field if you like.
    3. Click Pick a Name.
    4. See the winner; keep going or clear to start over.

    Practical Examples

    • Choose a winner from 50 giveaway entries.
    • Pick who presents first at a team meeting.
    • Select a random participant for a classroom activity.

    Key Features

    • Paste any list, one name per line
    • Random pick with a single click
    • Option to remove picked names
    • 100% local processing
    Privacy: Names are processed locally in your browser. They are never uploaded to or stored on a server.

    Frequently Asked Questions

    Does it remove the name after picking?

    You can choose 'Remove picked name' to prevent repeats, or leave it off to allow the same name to be picked again.

    Can I use it for a large list?

    Yes, within reasonable limits. Thousands of names work, though extremely large lists are slower to process.

    Is it fair?

    Yes. We use a secure random source, so each name has an equal chance.
