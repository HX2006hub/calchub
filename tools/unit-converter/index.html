Unit Converter

Convert between units of length, mass, temperature, speed, area and volume with accurate, tested factors. Temperature uses the correct formulas rather than a simple factor.

—
Pick units and enter a value.

How to Use

  1. Select a category (e.g. Length, Temperature).
  2. Choose the input unit and output unit.
  3. Type the value to convert.
  4. See the result instantly, updated live.

Practical Examples

  • Convert 5 feet 6 inches to centimetres — useful for health forms.
  • Convert 25 kilograms to pounds for a shipping label.
  • Convert 30°C to Fahrenheit for a weather forecast: 86°F.

Key Features

  • Length, mass, temperature, speed, area and volume categories
  • Correct temperature conversion formulas
  • Live conversion as you type
  • Large set of common units
Privacy: Conversions run locally in your browser. No input is stored or sent anywhere.

Frequently Asked Questions

Which units are included?

We cover the most common units in each category: metric and imperial for length and mass, Celsius/Fahrenheit/Kelvin for temperature, mph/kph/knots for speed, plus common area and volume units.

How is temperature converted?

Using the standard formulas: °F = °C × 9/5 + 32, and the reverse for °C to °F. Kelvin uses its offset correctly.

Are conversion factors rounded?

We use precise factors and round only the final display. Results are accurate for practical purposes.
