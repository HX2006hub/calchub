QR Code Generator

Turn a URL or any short text into a scannable QR code. Preview it instantly, choose the size, and download it as a PNG for print or web use.

How to Use

  1. Type a URL or any text into the input.
  2. The QR code preview updates automatically.
  3. Pick the size you need (256–1024 px).
  4. Download the QR code as a PNG.

Practical Examples

  • Generate a QR code for a business card linking to your website.
  • Add a QR code to a poster for a product page or event.
  • Create a Wi-Fi or contact code placeholder (text-based) for testing.

Key Features

  • QR code from any text or URL
  • Instant preview
  • Size selection up to 1024 px
  • PNG download
  • Empty input and very long input warnings
Privacy: QR codes are generated locally using a bundled open-source library. Your input is not sent to any server.

Frequently Asked Questions

What can I put in a QR code?

Any text, but a URL is most common. Email addresses, plain text and short IDs also work. Very long inputs create denser codes that are harder to scan.

Why is my input too long?

QR codes have a practical capacity limit. Text over a few hundred characters may not fit or may become too dense to scan reliably. We warn you when that happens.

Can I use the PNG anywhere?

Yes. It is a standard PNG you can use in print, websites or documents, as long as the code remains readable.
