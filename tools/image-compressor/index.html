Image Compressor

Reduce the file size of JPG, PNG or WebP images without uploading them anywhere. Adjust the quality slider and compare the original and compressed sizes in real time.

Drop an image here or click to browse

JPG, PNG or WebP — processed locally, never uploaded

Output is re-encoded as JPEG. Transparent PNGs lose their alpha channel when compressed to JPEG.

How to Use

  1. Click the upload area to choose an image, or drag and drop one.
  2. Move the quality slider to find the right balance between size and quality.
  3. Check the original vs compressed file size and the savings percentage.
  4. Download the compressed image when you are happy with the result.

Practical Examples

  • Compress a 2.4 MB product photo to a fast-loading web image.
  • Shrink large PNG screenshots before attaching them to an email.
  • Prepare JPG photos for a portfolio where load speed matters.

Key Features

  • Compresses JPG, PNG and WebP images
  • Quality slider for size/quality balance
  • Shows original vs compressed size and savings
  • Result is clearly labelled if compression increases file size
  • Fully local — the file never leaves your browser
Privacy: Your images are processed entirely in your browser. Files are never uploaded to a server, so nothing is stored or transmitted.

Frequently Asked Questions

Which formats are supported?

JPG, PNG and WebP images work in all modern browsers. HEIC and other niche formats depend on browser support and may not be available.

What if the 'compressed' file is bigger?

This can happen with already-compressed images or at very high quality settings. We show the real before/after sizes and never claim a compression that did not happen.

Is there a file size limit?

Practical limits depend on your device and browser memory. Very large images may be slow to process, but ordinary photos and screenshots work fine.
