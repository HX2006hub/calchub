Password Generator

Create strong, random passwords on your own device using cryptographically secure randomness. Choose the length and character types you need — nothing is stored, logged or transmitted.

How to Use

  1. Choose a password length (we recommend at least 14 characters).
  2. Tick the character types you want: uppercase, lowercase, numbers and symbols.
  3. Click Generate for a new random password.
  4. Copy the password securely to your clipboard.

Practical Examples

  • A 16-character password with all four character types has roughly 100 bits of entropy.
  • Generate a unique password for a new account instead of reusing one.
  • Create a strong master password that is easy for you to type but hard to guess.

Key Features

  • Cryptographically secure randomness (Web Crypto, not Math.random)
  • Custom length from 4 to 128 characters
  • Selectable character sets
  • Copy to clipboard
  • Passwords are never stored or transmitted
Privacy: Passwords are generated locally using your browser's Web Crypto API. They are never stored, never sent to a server, and disappear when the page closes.

Frequently Asked Questions

Is this really random?

Yes. We use the Web Crypto API's crypto.getRandomValues(), a cryptographically secure random source approved for security-sensitive use. We do not use Math.random().

What password length should I use?

12+ characters is a good minimum for most accounts; 16+ is better for anything important. Longer passwords add more entropy and are harder to brute-force.

Are my passwords stored?

No. They exist only in your browser's memory. Close the page and they are gone. Consider using a reputable password manager to store them.
