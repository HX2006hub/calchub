Frequently Asked Questions

Do you generate .ico files?

We generate PNG favicons in standard sizes, which work in all modern browsers. We do not fake .ico files by renaming PNGs, because that produces unusable icons.

Which favicon size should I choose?

32×32 is the most common size for a browser tab. Use 48×48 or 64×64 for higher-density displays, and 128×128 if you need a larger source to scale down elsewhere. This tool exports one size at a time as a PNG.

Does the source need to be square?

The image is fitted into a square canvas with a solid background, so a non-square logo will still work — check the preview before downloading.
