Frequently Asked Questions

Do you generate .ico files?

We generate PNG favicons in standard sizes, which work in all modern browsers. We do not fake .ico files by renaming PNGs, because that produces unusable icons.

Which favicon size is most important?

32×32 (browser tab) and 16×16 (fallback) are the most important for desktop browsers. 192 and 512 px are used by mobile home screens.

Does the source need to be square?

We crop the source to a square automatically, focusing on the centre, so a non-square logo will still work — check the preview.
